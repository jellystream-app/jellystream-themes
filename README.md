# 🎬 Jellystream — Custom CSS & Style Repository

Willkommen im offiziellen Styling-Repository für **Jellystream**.

Dieses Repository dient als zentraler **Theme Store** für [jellystreams.app](https://jellystreams.app). Hier findest du maßgeschneiderte CSS-Anpassungen und Design-Setups, mit denen du das Aussehen deines Jellystream-Clients individuell gestalten und personalisieren kannst.

---

## 🚀 Nutzung & Installation

1. Öffne deine Instanz von **Jellystream** ([jellystreams.app](https://jellystreams.app)).
2. Navigiere zu **Einstellungen** (`Settings`) → **Aussehen** (`Appearance`).
3. Scrolle zum Feld **Eigenes CSS** (`Custom CSS`).
4. Kopiere den gewünschten CSS-Code und füge ihn in das Textfeld ein.
5. Speichere die Einstellungen und lade die Seite neu (`Strg + F5` / `Cmd + Shift + R`).

---

## 🛠 Mitwirken (Contribution)

Du hast eigene Styles für Jellystream entwickelt oder möchtest neue UI-Elemente hinzufügen? Pull Requests sind jederzeit willkommen!

1. Forke das Repository
2. Erstelle einen Feature-Branch (`git checkout -b feature/mein-style`)
3. Committe deine Änderungen (`git commit -m 'Add: Neues UI-Styling'`)
4. Pushe den Branch (`git push origin feature/mein-style`)
5. Öffne einen Pull Request
